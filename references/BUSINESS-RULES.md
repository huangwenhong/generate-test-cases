## 按钮

> 适用：任何触发操作的按钮、链接、图标按钮

### 通用规则

| 场景 | 测试要点 |
|------|---------|
| 防重复点击（正常网络） | 点击后立即进入 loading/禁用态，请求完成前不可再次触发 |
| 防重复点击（弱网） | 弱网下连续点击，不会重复生成/更新数据 |
| 禁用态 | 条件不满足时按钮置灰，点击无响应 |
| 加载态 | 异步操作期间显示 loading，完成后恢复 |

### 提交/确定/保存按钮（必须生成 4 条用例）

| 用例 | 测试要点 |
|------|---------|
| 1. 校验拦截 | 必填项为空时点击，展示错误提示且不提交 |
| 2. 提交成功 | 所有字段合法时点击，数据正确生成/保存 |
| 3. 正常网络防重 | 快速连续点击，按钮进入禁用/loading，不重复提交 |
| 4. 弱网防重 | 弱网下连续点击，不会重复生成/更新数据 |

### 取消按钮（必须生成 2 条用例）

| 用例 | 测试要点 |
|------|---------|
| 1. 二次确认 | 点击取消弹出确认提示（如"未保存内容将丢失，是否确认？"） |

## 阶梯/区间配置

> 适用：运距区间、价格阶梯、数量折扣等需要动态添加多行区间的配置场景

### 通用规则

| 场景 | 测试要点 |
|------|---------|
| 初始默认行 | 首次进入展示 1 行空配置，第一行起始值固定为 0 |
| 添加行 | 在最后一行下方新增；若当前行必填字段未完成则 toast 拦截 |
| 删除行 | 行数 > 1 时显示删除按钮，固定在最后一行；仅剩 1 行时隐藏 |
| 区间起始值 | 第一行固定为 0；后续行起始值 = 上一行结束值；上一行结束值未填则展示空 |
| 区间结束值 | 必填，必须大于起始值；修改后若后续区间值小于当前值则自动清空 |
| 单位值 | 必填，限制小数位数；失焦时 toast 未填完全 |
| 保存 | 所有区间填写完整后保存成功；有空值行时拦截 |
| 切换模式 | 切换配置方式（如区域↔运距）后保存，未选中模式的数据被清空 |
| 默认选中 | 首次未配置时默认选中第一选项；配置过后默认展示上次选项和数据 |

### 必须生成的用例

| 用例 | 测试要点 | 优先级 |
|------|---------|--------|
| 1. 完整流程 | 初始 1 行 → 填写 → 添加行 → 填写 → 保存成功 | P1 |
| 2. 边界值 | 起始值 < 结束值、范围边界（1-10000） | P2 |
| 3. 必填校验 | 单位值未填时失焦 toast、添加行时上条未完成拦截 | P2 |
| 4. 删除区间 | 2 行以上可删，1 行时按钮隐藏 | P3 |
| 5. 联动清空 | 修改起始值后，后续区间值自动清空 | P3 |
| 6. 切换清空 | 切换配置方式保存后，未选项数据清空 | P4 |

## 配置取值优先级

> 适用：同一参数可从多个来源获取，按优先级选取

| 场景 | 测试要点 |
|------|---------|
| 优先级链 | 按需求指定的优先级取第一个有值的来源（如 市场价 > 库存价） |

| 全部为空 | 所有来源均未配置时返回 0 或展示兜底值 |
| 实时性 | 修改配置后计算结果即时更新，不走缓存 |
