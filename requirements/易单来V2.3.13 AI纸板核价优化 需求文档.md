# 易单来V2.3.13 AI纸板核价优化 需求文档

> UI 图目录：`requirements/UI图/2.3.13AI 纸板核价优化UI/`



## 一、核价配置

### 1. 使用角色配置

- 1. 角色默认为空，显示"暂无角色配置"的缺省页面。
- 2. 点击"添加角色"在表格中新增一行：

	- 角色名称：直接输入，最多 10 个字。最多只能新增10个角色
	- 成员：下拉多选，最多选择 50 人；超出上限则无法选择，toast 提示"超出人员上限"。

- 3. 点击"保存"：

	- 角色名称为空 → toast 提示"角色名称未填写"。
	- 成员允许为空。
	- 保存后刷新原纸价格配置列表的角色信息
	- 保存后刷新楞率配置列表的角色信息

- 4. 点击"编辑"进入编辑状态，可修改角色名称与成员。
- 5. 点击"删除"：

	- 内容均为空时，直接删除。
	- 有填写任意内容时，弹出二次确认弹窗

		- 文案"确定要删除该角色配置吗？"，确认后删除数据。

### 2. 原纸价格配置

- 1. 单选，默认为"固定取人工测算价格"，为必填项。
- 2. APP 核价时支持根据不同角色，用不同的价格进行核算并展示。
- 3. 角色取自上方保存的"使用角色配置"。
- 4. 支持配置不同角色计算价格时使用的原纸利用率：输入框，单位 %，整数位最多 3 位、小数位最多 4 位（0 – 999.9999）。

### 3. 楞型选项配置

- 1. 支持配置不同层数下可选择的楞型选项。
- 2. 层数 tab 固定二层至七层。
- 3. 可在下拉选项框中选择对应层数要展示的楞型；

	- 多选，数量不做限制；
	- 可以为空。

- 4. 点击"删除"按钮可去除该楞型。
- 5. 对应层数的楞型枚举：

	- 2 层 / 3 层：A / B / C / D / E / F
	- 4 层 / 5 层：AA / AB / AC / AE / BB / BC / BE / CC / CE / EE / EB
	- 6 层 / 7 层：BAA / BAB / BAC / BCA / BCB / BCC / BEE / CAC / CEB / EBA / EBC

### 4. 楞率配置

- 1. 支持按角色配置核价时使用的楞率；

	- 角色取自上方保存的"使用角色配置"。

- 2. 必填项，初始数据默认为空；

	- 保存时校验到有楞率未填写时，toast 提示"楞率配置未完善"。
	- 填写完整时保存成功

- 3. 列固定为 A 楞 / B 楞 / C 楞 / E 楞 / F 楞。
- 4. 表格支持输入，仅支持数字，整数位最多 1 位、小数位最多 4 位（0 – 9.9999）。

### 5. 加工费配置

- 1. 层数 tab 固定二层至七层。
- 2. 在偶数层（2 / 4 / 6 层）配置的"特殊面纸加工费"，在核价时默认视为对"里纸"进行判断。

### 6. 审批配置

- 1. "调价空间"仅在选择"是"时生效，仅支持输入数字，整数位最多 1 位、小数位最多 2 位，单位元/㎡。
- 2. APP 核价时可向下或向上调整该调价范围。
- 3. 允许为空；若为空则不限制调价范围。

## 二、核价审批记录

### 1. 导出

- 1. 点击"导出"按钮，将列表筛选时间的数据进行导出；

	- 导出模板按提供的为准。

### 2. 列表

- 1. 新增"层数楞型"、"价格类型"字段，取数来源为 APP 核价时填写的数据。

## 三、原纸价格

### 1. 新增"含税设置"按钮

- 1. 点击后打开"含税设置"弹窗。
- 2. 新增"原纸价格是否含税"标签，选项为"含税 / 不含税"，默认选中"含税"。
- 3. 该标签对列表全部原纸代码适用（全局生效，不分代码）。
- 4. 若选择"不含税"，则核价时需在纸价基础上 × 1.13。

### 2. 人工测算 - 批量导入

- 1. 导入模板中"原纸代码"允许输入特殊字符，例如"+"。
