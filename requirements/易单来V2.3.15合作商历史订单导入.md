## 一、版本核心变化摘要

V2.3.15 将 V2.3.14 的"同步导入"重构为**异步任务模型**，并落实大数据量（吉盛月十几万条）场景：

1. **模板收敛为 15 列**：删除「长、宽、高、压线方式、重压（纵压）方式」5 个字段，仅保留「落料长、落料宽」两列尺寸；新增「业务员」列。
2. **取消 1 万条导入上限**：单文件不设业务行数上限，技术方案支持 10 万条（会议确认，每批 500 行流式暂存）。
3. **尺寸单位自动化**：单位（cm/mm）由后端查询供应商配置获得，前端不再选择/传入；单位展示在**表格数据行内**而非表头。
4. **导入记录新增两类进度**：本地导入进度（successCount/totalCount）+ 大数据同步进度（syncedCount/successCount），前端定时轮询（约 5 秒）。
5. **并发与防重规则明确**：同一文件地址防重、同一真实供应商同时只允许一个未结束导入任务（Redis 锁）。
6. **历史业务员绑定关系**：不做自动化批量调整，人工手动处理（会议决策）。

### 2.6 导入记录与进度（新增核心）

| 项 | 状态 | 说明 |
| --- | --- | --- |
| localStatus | 🆕 | QUEUED 排队待执行 / RUNNING 暂存或处理中 / SUCCESS 全部行成功 / PARTIAL 部分行成功 / FAILED 全部行失败、文件级校验失败或任务中断（中断时可能已有成功订单）；未结束时按 localStatus 展示"排队中/导入中"，**尚未确定的计数不填成 0** |
| 导入进度 | 🆕 | 前端以 successCount/totalCount 对比展示；totalCount=完整暂存后的非空行数（未完整暂存为 null）；failCount 任务未结束时为 null |
| reportStatus | 🆕 | NONE / BUILDING（生成、上传、恢复重建中）/ READY（可下载）/ FAILED；报告失败不改变 localStatus；前端按状态显示"生成中/失败/下载入口" |
| 大数据同步进度 | 🆕 | syncedCount 取大数据 `statistics_order_cnt`（**含已取消/逻辑删除订单**）；展示 syncedCount/successCount（分母是本地成功数，不是文件总数）；仅当前页**本地已终结且 successCount>0** 的任务逐条查询；未终结=null 显示本地状态；终结且无成功订单不查询、显示"无成功订单，无需同步"（不计算 0/0） |
| 进度查询降级 | 🆕 | 单条失败/超时/缺计数/越界 → 该条 syncedCount=null 显示"同步进度暂不可用"，其余字段与分页照常返回；正常返回 0 必须保留为 0；整页耗时预算约 3 秒，预算耗尽未查项返回 null，不重试 |
| 前端轮询 | 🆕 | 弹窗打开时定时（会议建议 5 秒）刷新当前页；关闭停止；当前页任务均终结、报告不在生成、进度完成/无需同步后可停止自动刷新 |
| errorMessage | 🆕 | 文件级/任务级脱敏失败原因（表头不符、文件无法读取、任务中断等）；行级原因走错误报告；报告与大数据进度失败不覆盖该字段 |
| 操作结果组合 | 🔄 | 「导入X条，成功Y条，失败Z条；创建客户档案M家，产品档案N条」；已有产品复用不计新增；成功数不因后续删除追减 |
| 记录可见范围 | ⚠️ | **api/plan 与会议纪要冲突**：api §4、plan 1.1.16 说按"当前公司+当前用户"过滤（仅本人）；纪要说"可见其他人的记录，而非仅限本人"。见 §六 待确认 C-1 |
| 不返回字段 | 🆕 | 不再返回 fileName、sizeUnit、processedCount（纪要待办中"增加处理条数字段"已被 api 最终版推翻，前端用 success/total 计算） |

## 三、接口契约速览（本服务 6 个，前缀 `/DJEASYORDER/order/v2/`，均 POST）

| 接口 | 入参要点 | 出参要点 |
| --- | --- | --- |
| `importHistoryOrder.do` | fileUrl（唯一入参，无 sizeUnit） | taskId + localStatus=QUEUED；同步拒绝场景见 §2.2/2.9 |
| `downloadHistoryOrderTemplate.do` | `{}` | xlsx 文件流；模板地址来自系统变量 EASY_ORDER_HISTORY_ORDER_TEMPLATE_URL，未配置返回错误不返回空文件 |
| `getHistoryOrderList.do` | 分页+筛选（见 §2.8） | PageResult<HistoryOrderVo>（含 sizeUnit，无长宽高/压线/纵压） |
| `getImportTaskList.do` | pageNo/pageSize | PageResult<HistoryOrderTaskVo>（含 localStatus/reportStatus/errorMessage/canDownloadErrorReport/syncedCount/四类计数）；无单独详情接口 |
| `downloadErrorReport.do` | taskId | 15 列+错误原因 xlsx；状态与归属门槛见 §2.7 |
