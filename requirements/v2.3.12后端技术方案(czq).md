# 易付通还款通知 - 后端技术方案

## 1. 需求背景

### 1.1 现状

易付通侧已具备还款结果汇总能力，需要将汇总后的还款通知发送到 CRM 服务，由 CRM 生成 App 站内消息并发送 App 横幅 Push。

本次新增“易付通还款通知”消息类型，消息接收人包括：

1. 当前供应商下，该客户绑定的业务员；
2. 当前供应商属于联合供应商时，联合供应商销售主体下，该客户绑定的业务员。

---

## 2. 数据库设计

### 2.1 新增还款通知消息表

建议表名：`crm_repayment_notice_message`

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | char(32) | 主键 |
| notice_type | varchar(32) | `PAYMENT_FAILED` / `AUTO_PAID` |
| source_supplier_id | varchar(32) | 事件来源供应商 ID，即易网传入的 supplierId |
| skey | varchar(32) | 消息归属供应商真实 ID |
| customer_id | varchar(64) | 客户 ID |
| customer_name | varchar(255) | 客户名称快照 |
| supplier_name | varchar(255) | 事件来源供应商名称快照 |
| user_id | varchar(32) | 接收消息的业务员 ID |
| user_name | varchar(100) | 接收消息的业务员名称 |
| repayment_amount | decimal(18,2) | 还款金额 |
| content | text | 含 `<warning>` 标签的完整消息正文 |
| create_time | datetime | CRM 创建时间，也是 App 展示时间 |
| update_time | datetime | 更新时间 |
| isdel | tinyint | 删除标识 |

---

## 3. 易网接口对接

### 3.1 生成还款通知（新增）

**接口路径**：`/message/repayment/sendMessageCommon.do`

**API地址**：http://172.17.0.71:3000/project/486/interface/api/159985

**接口说明**：易网按日汇总客户还款结果后，批量调用 CRM 生成站内消息并发送 App 横幅 Push。


---

## 4. App 接口设计

### 4.1 查询还款通知列表（新增）

**接口路径**：`/message/app_getUserRepaymentMessageList.do`

**API地址**：http://172.17.0.71:3000/project/486/interface/api/159994

**接口说明**：查询当前登录用户、当前真实供应商下的还款通知，按创建时间倒序分页返回。

### 4.2 查询各消息类型未读数（修改）

**接口路径**：`/message/app_getUnreadMessageNumber.do`

**API地址**：http://172.17.0.71:3000/project/486/interface/api/58565

**改动内容**：

1. 增加 `templateType = 7` 的还款通知未读数；
2. 增加还款通知最后一条消息；
3. 还款通知未读数计入全局未读总数；
4. `lastMessage.content` 原样返回 `<warning>` 标签；
5. 未读查询必须同时使用当前用户 ID 和当前真实供应商 ID。


### 4.3 查询最近未读消息（修改）

**接口路径**：`/message/app_getLatestUnreadMessages.do`

**API地址**：http://172.17.0.71:3000/project/486/interface/api/144141

**改动内容**：

1. 还款通知参与全局最近三条未读消息排序；
2. 还款通知未读数计入全局未读总数；
3. 返回项通过 `templateType = 7` 标识消息类型；
4. 返回的消息正文保留 `<warning>` 标签；
5. 排序时间使用 CRM `create_time`。


### 4.4 按消息模板标记已读（修改）

**接口路径**：`/message/app_messageReadForTemplate.do`

**接口路径**：http://172.17.0.71:3000/project/486/interface/api/112514

**改动内容**：

1. `templateType` 支持还款通知类型 7；
2. 将当前登录用户、当前真实供应商下的还款通知标记为已读；
3. 现有“全部已读”逻辑需要同时覆盖还款通知；
4. 响应结构沿用现有接口。


---

## 5. 异常与边界处理

1. 单批建议最多 500 条；
2. 一条失败只回滚当前明细，不回滚整批；
3. 易网对同一批数据重复调用时，CRM 会再次落库并再次 Push，不做去重。
